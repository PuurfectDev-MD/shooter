# Candy Shooter
A 2-axis joystick-controlled device that shoots candy straight at your face.

## How We Built It
* **Aim & Movement:** Two servos provide precise 2-axis (X and Y) pan-and-tilt control.
* **Shooting Mechanism:** Dual DC flywheel motors spin inward to grip and launch the candy.
* **Dispensing:** A third DC motor drives a slider mechanism to feed candies one by one.
* **Range Control:** A potentiometer lets you adjust the motor speed to control how far the candy shoots.
* **Smart Targeting:** Camera conected to the phone handles real-time object detection, triggering a shot when it detects an open mouth or a specific gesture (6-7 gesture).

## Features
* Accurate manual joystick aiming
* Adjustable shooting range via motor speed control
* Automatic dispensing mechanism
* Fast, responsive shooting
* Hands-free auto-fire via face/gesture tracking
